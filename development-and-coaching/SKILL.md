# 员工发展与教练 (Development & Coaching)

## R — 核心要旨 (Reading)

需求评估是识别员工所需知识、技能与能力以推动组织前进的流程, 也是定位绩效差距、识别新技能需求的方法; 许多组织犯的错, 就是跳过这关键一步。

---

## I — 方法论骨架 (Interpretation)

发展员工是组织与经理的责任, 不是员工的运气:

1. **先评估后设计**: 用绩效评审中的发展建议、员工/经理访谈、焦点小组 (5-12 人)、问卷、现场观察等多种方法交叉验证真实需求, 再决定开发什么; 跳过需求评估直接开课是常见且昂贵的错误。
2. **设计发展方法**: 培训/导师制/教练/内部流动各有适用——培训要管理者跟进否则学习蒸发; 导师用引导句让 mentee 先开口; 教练按五维选人、五步走 (初会→评估→反馈→目标→定期会谈), 周期 3-6 个月, 客户主导议程、引导而非指挥。
3. **守住承诺纪律**: 发展对话围绕技能提升, 绝不承诺"上完课就晋升"; 需求评估阶段也不能许愿。
4. **内部流动**: 晋升分竞争性 (空缺, 是选拔决策, 更受审视, 必须公平且文档化) 与非竞争性 (组织/岗位变化); 落选者要被告知原因与下一步发展建议。
5. **教练关系高度保密**: HR 不打听教练会谈内容, 了解进展只问客户本人或其经理。

读完以上要点, 应能理解: 发展 = 先评估 → 选方法 → 不承诺 → 保密地执行, 且"培训-晋升挂钩"和"把教练当修理工具"是两个反直觉禁忌。

---

## A1 — 应用案例 (Past Application)

### 案例 1: 被忽略晋升的员工, 周一递交辞职信
- **问题**: 骨干员工被资历更浅、技能更少的同事抢走晋升, 感到公司不再重视自己。
- **方法论的使用**: 案例用这个开篇案例引出"内部晋升流程必须可感知为公平"——竞争性晋升即选拔决策, 落选者要被告知具体原因与下次被考虑所需技能。
- **结论**: 不透明或不公平的晋升会直接触发高绩效者离职。
- **结果**: 员工冷静周一面谈后, 从文件夹里滑出辞职信。

### 案例 2: 师徒引导句 + 零成本"午餐学习会"
- **问题**: 师徒第一次见面没话聊; 预算为零仍要做领导力输入。
- **方法论的使用**: 方法提供引导句模板 (我自豪于…… / 我需要注意…… / 我期待…… / 我要谨慎…… / 我想让同事理解…… / 我的职业目标是……) 让 mentee 先开口; 用"录 CEO 讲座 + 员工自带午餐观看 + HR 收集问题邮件答疑"做零成本培训闭环, 并配套课后评估表。
- **结论**: 发展不需要昂贵项目, 结构化引导与零成本机制也能落地。
- **结果**: 学习会成为可规模化、可评估的低成本发展方法。

### 案例 3: 内部调动政策——防"借道甩差员工"
- **问题**: 想鼓励内部流动, 又怕经理借调动把差员工甩给别人。
- **方法论的使用**: 样张政策设三道护栏——资格门槛 (任职满一年 + 不在 PIP 上)、内招先于外招 5 个工作日、落选者必须获得改进反馈。
- **结论**: 政策设计要让流动成为发展而非损耗。
- **结果**: 内招优先 + 资格限制 + 落选反馈成为内部人才流动的样板机制。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 员工或团队需要成长规划, 但不确定缺什么——要做需求评估。
2. 公司要做培训/发展项目, 预算有限, 或担心花钱没效果。
3. 要建立/维护导师制或教练项目, 或为某位高管选教练。
4. 员工追问"学完这个会不会晋升", 或晋升名单引发内部争议。
5. 想用内部调动、轮岗来发展人才, 需要设计规则。

- "发展" / "development" / "成长" / "grow" / "职业规划" / "career path"
- "晋升" / "promotion" / "升职" / "内部调动" / "transfer" / "轮岗"
- "培训" / "training" / "课程" / "导师" / "mentor" / "带教"
- "coach" / "coaching" / "教练" / "高管辅导" / "陪跑"
- "选教练" / "hire a coach" / "接班人" / "succession" / "储备"

### 与相邻 skill 的区分

- 与 `performance-management` 的区别: 发展管**未来的能力与成长**, 绩效管**当下的职责达标与改进**。需求评估可以吃进绩效评审的建议, 但 PIP 解决当下差距, 教练/培训服务未来潜能; "修好他"式教练请求 (绩效差找人修理) 应回到绩效管理或纪律, 而不是教练。
- 与 `recruiting-and-hiring` 的区别: 内部培养 (build) vs 外购人才 (buy) 是同一人才缺口的两种解法; 有缺口先判断"能否内部流动/培养", 再决定是否启动外部招聘。
- 与 `workforce-planning` / 继任规划的区别: 继任在组织层 (关键岗位人才管线), 本 skill 在个人层 (个体发展项目); 继任名单是需求评估的一种数据源, 不在此构造。
- 与 `termination-and-layoff` 的区别: 不给成长机会导致骨干离职属于留任问题, 与解雇无关; 晋升落选的争议走内部流动公平程序, 不自动进入解雇流程。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **需求评估 (先评估后设计)**
   - 完成标准: 用 ≥2 种方法交叉 (绩效建议 / 访谈 / 焦点小组 5-12 人 / 问卷 / 观察) 输出"需求清单 + 证据"; 已向利益相关方校准预期 (不承诺建议都会实现); 数据收集前已提前告知观察安排。

2. **设计并落地发展方法**
   - 完成标准: 每个需求对应至少一种方法 (培训 / 导师 / 教练 / 内部流动), 各有负责人、时间表与跟进机制; 培训含课后评估与管理者跟进; 若用教练, 按五维 (经验 / 成果 / 培训 / 理念 / 认证) 选人并走五步流程。
   - 判停条件: 若需求本质是"当下绩效不达标", 转 `performance-management` 处理 (PIP), 不派教练"修理"。

3. **守住承诺纪律 + 保密边界**
   - 完成标准: 全部发展对话记录中无"上完课就晋升"式承诺, 对话围绕技能差距与成长路径; 教练项目中 HR 只联系客户本人或其经理了解进展, 不向教练打听会谈内容。

4. **评估与闭环**
   - 完成标准: 培训有课后评估表并年度汇总; 用行为改变与组织结果 (而非"多少人上课") 判断效果; 内部流动/晋升落选者均收到原因 + 发展建议并留档。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 当下绩效差距 (完不成任务)——先走绩效归因与 PIP, 不派教练。
- 行为/纪律问题——不派教练, 走纠正式纪律。
- 纯组织层继任规划——那是 workforce-planning 的领域 (可提供数据源)。
- 用户想"内定"晋升人选绕过选拔——竞争性晋升必须公平且文档化。

### 常见失败模式

- **承诺晋升**: 说"上完课就晋升"制造 entitlement, 未兑现时可能构成默示合同纠纷——绝不作任何承诺, 对话围绕技能提升。
- **培训不跟进**: 培训后不强化, 学习就蒸发——管理者的跟进才是成败关键。
- **不给成长必反噬**: 怕失去人才就不给成长机会, 反而加速人才以离职为代价自找出路。
- **教练当修理工具**: 把教练当惩罚性修理手段会同时毁掉教练价值与员工信任——除非关键岗位高管, 否则"修人"需求应用绩效管理等其他干预。
- **晋升流程不透明**: 落选的优秀员工感到不再被重视, 当天递交辞呈。

### 方法论局限 / 适用边界

- "默示合同"是美国法概念, 承诺晋升在不同司法辖区的风险需本地化确认。
- 假设组织有成型 HR、预算与信息系统; 对无预算团队, 零成本做法 (午餐学习会) 是方法给出的降级方案。
- 大公司 (Fortune 500) 语境下的"最佳实践"未必适配小团队/创业公司——需求评估的规模可大可小, 别照搬完整调研。
- 代际本质主义: 别把"千禧一代需要特殊管理"当成方法论输入。

### 容易混淆的邻近方法论

- **教练 vs 导师**: 教练不提供建议、客户主导议程、有时限 (3-6 个月)、高度保密; 导师分享经验与建议、关系更长期。
- **教练 vs 绩效辅导**: 教练不评估不纠偏; 绩效辅导直接评价并设定改进目标。
- **培训 vs 发展**: 培训是事件, 发展是持续过程; 单次课程不等于发展承诺。
- **晋升 vs 薪酬**: 晋升类型 (竞争/非竞争) 决定流程与受审查程度; 薪酬数字由 compensation 决定。

## 快速理解: 5 个示例问题

用这 5 个最常被问到的场景快速上手本 skill, 每个问题都对应它真正触发的处理动作:

1. **想评估团队到底缺什么能力, 培训该怎么设计?** — 需求评估 (≥2 种方法交叉) 再设计发展
2. **要为一位高管选教练, 怎么选?** — 五维选教练 (经验/成果/培训/理念/认证)
3. **员工问'学完这个会不会晋升', 我怎么回应?** — 承诺纪律: 不承诺晋升, 只谈技能提升
4. **想建导师制和内部轮岗, 怎么设计规则?** — 内部流动政策设计 (资格门槛/内招优先/落选反馈)
5. **公司想推人才发展项目, 但预算为零。** — 零成本方案 (午餐学习会/内部导师/引导句)
