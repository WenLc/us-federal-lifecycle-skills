# 文档化与政策 — 证据纪律、员工手册与工会合规

## R — 核心要旨 (Reading)

事件一发生就做持续书面记录, 不要等严重问题出现才补写。每次记录写明日期/时间/地点、涉事者全名, 写简短具体、聚焦行为的条目, 加上让第三方 (乃至陪审团) 无需上下文就能看懂的说明; 只写与工作相关的事实、不下结论, 具体客观、剔除臆测。

---

## I — 方法论骨架 (Interpretation)

文档不是事后补的诉讼材料, 而是平时就要铺设的证据护城河。骨架分四条线: (1) 文档纪律——问题刚出现就实时记录, 结构化地写日期/时间/地点/涉事者全名/聚焦可观察行为, 加说明让第三方 (或陪审团) 读得懂, 只记事实不下结论不写推断, 好事坏事、非正式警告与辅导都记, 署名日期、存于安全但管理层可及处; "文档即保护", 也是绩效/晋升/解雇决策可辩护的基础。(2) 政策设计——政策是"灵活的管理指南"而非把判断空间堵死的僵硬律条, 抵制复制粘贴别家模板; 要防的是"未成文的实际做法"悄悄变成员工可依赖的事实政策, 侵蚀 at-will 等法律保护, 因此成文政策必须与实际做法一致。员工手册配四件套: at-will 声明、针对本组织定制、员工签字确认已阅读、政策更新后重新签字。(3) 纪律流程——先做"行为 vs 绩效"二分: 行为问题 (工作场所不当举止) 用纠正式纪律阶梯, 绩效问题 (能力上完不成任务) 用 PIP; 纪律阶梯从哪一级进入由行为严重度决定, 不必逐级走, 判断不能被流程抽走。(4) 工会合规——NLRA 语境下管理者在工会话题有 TIPS 四不红线 (威胁/盘问/许诺/监视), 一个"孤立小事件"集合可能构成工会运动证据; 但合法沟通不是禁区——如实答问题、直白讲政策、听员工主动提供的信息都是被允许的。

## A1 — 应用案例 (Past Application)

### 案例 1: 文档化指南 — 记录规范
- **问题**: 管理动作 (纪律、晋升、解雇) 需要在证据上可辩护, 但多数人只在出事后才想起写材料。
- **方法论的使用**: 方法把记录规范写成操作流程: 事发即记、连非正式警告与辅导都记、也记正面成就、对所有员工一致记录; 事件日志含时间地点、全名、聚焦行为、第三方可懂、只记事实不注来源。
- **结论**: 记录的价值在于及时、完整、客观、一致——补写的文档既不可信也无法律价值。
- **结果**: 文档从"临到解雇才补"变成贯穿全生命周期的持续纪律。

### 案例 2: 员工手册签收回执 — 把 at-will 落成可证明的文档
- **问题**: 手册里写了大量保障性措辞, 若不设防, 会被法院认定为"默示合同", 侵蚀就业自由。
- **方法论的使用**: 用签收回执把边界写死: 手册仅作指引非合同、公司可随时修改、雇佣基于双方同意可随时终止、除 CEO 外无人有权订立雇佣协议。
- **结论**: "手册非合同 + 员工已明知 at-will"需要可证明的书面证据, 光让员工签名不行, 措辞必须成套。
- **结果**: 收执成为防御默示合同/口头承诺的可复用模板, 手册正文同步删除一切暗示工作保障的表述。

### 案例 3: TIPS — 工会组织期间的四不记忆工具
- **问题**: 工会开始组织活动时, 管理者在压力下容易踩雷 (威胁、盘问、许诺、监视), 构成不公平劳动行为。
- **方法论的使用**: 方法给出 TIPS 四字诀 (Threats/Interrogation/Promise/Spy) 作为易记的"避免清单", 并配套工会期间的 Do/Don'ts。
- **结论**: 红线精确且对无工会企业同样适用——经理随口问"你们是不是在搞工会"即可能违法。
- **结果**: 管理者把"该做什么 (答问题/听自愿信息/报 HR)"和"绝不能做什么 (TIPS)"分开执行, 合法沟通不被冻结。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司没有员工手册、要重写手册, 或想搭手册目录与签收回执。
2. 员工有行为问题 (迟到/不服从/冲突), 要决定纪律起点、怎么写书面警告和记录。
3. 工会开始组织活动, 经理问"现在能对员工说什么、不能说什么"。
4. 出了事才发现没记录 / 在写事件日志, 不确定怎么写才有效、能不能补。
5. 政策与做法不一致 (多年默许的惯例 vs 书面政策), 需要校准与更新。

### 语言信号 (用户的话里出现这些就应激活)

- "员工手册 / handbook / 政策怎么定 / policy / 员工签字确认"
- "纪律处分 / progressive discipline / 书面警告 / written warning / 口头警告怎么记"
- "工会 / union / TIPS / unfair labor practice / 能不能劝员工别签卡"
- "文档 / 记录 / documentation / incident log / 事发记录 / 怎么记 / 现在补还来得及吗"
- "我们一直默许 X, 现在想严格执行, 有风险吗?" (未成文做法)

### 与相邻 skill 的区分

- 与 `termination-and-layoff` 的区别: 本 skill **生产**证据 (平时的记录纪律、手册、纪律流程), 终止 skill **消费**证据 (解雇决策与会议)。若解雇前缺文档 → 先回本 skill 建立记录纪律, 但补记不可信、别指望补旧账; 两者顺序上是"先文档, 后终止"。
- 与 `performance-management` 的区别: 绩效文档是绩效管理五要素之一; 本 skill 覆盖行为纪律 + 政策 + 工会, 范围更广且偏"证据纪律"; 绩效差距 (能力问题) 用 PIP, 行为问题 (不当举止) 才进纪律阶梯。
- 与 `harassment-and-investigation` 的区别: 调查也需要文档, 但那是事实存疑时的主动查证流程; 本 skill 是持续的、日常的证据记录与政策维护。
- 与 `employment-law-basics` 的区别: 后者解释法律概念 (at-will 的三大例外、歧视双理论); 本 skill 把 at-will 落成可证明的文件 (签收回执) 与可执行的纪律/工会流程。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **建立文档纪律 (若尚未有)**
   - 定下"事件一发生就记"的规矩与事件日志模板 (日期/时间/地点、全名、聚焦可观察行为、第三方可懂说明、信息来源), 并示范记录至少 1 条; 明确"好事、非正式警告、辅导对话都要记"。
   - 完成标准: 模板已定稿, 且记录里的每条都只含可验证事实、不含"他觉得/他不在乎"之类推断; 已签名署期。
   - 判停条件: 若用户想补写过去的旧账 → 明确告知"事后补记可信度低", 只从今天起记; 过去的问题用现有证据谨慎处理, 不得编造。

2. **审计与校准政策/员工手册**
   - 对照四件套 (at-will 声明、量体裁衣、签字确认页、更新后再签) 与手册目录骨架 (10 大板块: 签收/欢迎/雇佣关系/行为规范/绩效/日常/福利/薪酬/休假/安全); 逐条盘点"未成文的实际做法", 与书面政策比对。
   - 完成标准: 手册已有 at-will 声明 + 签收回执页 + 章节骨架; 产出一份"书面政策 vs 实际做法"的差异清单, 每条标出"改政策 or 纠正做法"。
   - 判停条件: 若政策冲突涉及"承诺工作保障/固定期限"的表述 → 优先删除或改写, 这是默示合同的最大来源。

3. **处理纪律处分 (若行为问题触发)**
   - 先做"行为 vs 绩效"二分; 行为问题按严重度选纪律阶梯起点 (口头 → 书面 → 最终书面 → 停职 → 解雇), 严重行为 (暴力/盗窃) 可直接高起点; 每次动作后记录, 书面警告须含日期/姓名/行为类别/观察到行为及日期/影响/纠正措施/升级警告。
   - 完成标准: 书面警告的要素齐全、只写事实; 记录对所有员工标准一致。
   - 判停条件: 若实质是能力问题 (完不成任务) 而非行为 → 移交 `performance-management` 用 PIP, 不得用纪律工具; 若达到解雇 → 移交 `termination-and-layoff`。

4. **工会合规 (若工会组织触发)**
   - 全员 (至少管理者) 记住 TIPS 四不 (威胁/盘问/许诺/监视); 对照 Do 清单 (如实答问题、直白讲政策、说明签卡即入会第一步、听员工主动提供的信息、立即处置暴力) 与 Don'ts (不盘问/不监视/不威胁/不承诺/不收卡/不问投票意向/不劝退卡); 任何拿不准的涉工会言行先报 HR/法务。
   - 完成标准: 管理团队能默写 TIPS 并指出哪类言行越线; 已建立"涉工会事项上报 HR/法务"的流程。
   - 判停条件: 若已出现潜在暴力或违规被曝光 → 立即上报并停止一切自行"沟通", 交由 HR/法务/调查流程处理。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一次性解雇/裁员的执行与会议 → 用 `termination-and-layoff` (本 skill 只是它的前置证据来源)。
- 已发生的骚扰/歧视投诉调查 → 用 `harassment-and-investigation`, 那是主动查证不是被动记录。
- 纯绩效差距 (能力问题) → 用 `performance-management` 的 PIP, 别用纪律工具。
- 非美国语境: at-will 与 NLRA/TIPS 是美国法律框架, 在其他司法辖区需替换为当地劳动法。

### 常见失败模式

- TIPS 四类不公平劳动行为——即使公司无工会, 威胁/盘问/许诺/监视也违法。
- 靠"未成文的做法/历史先例"管人, 以为没白纸黑字就不用负责 → 实际做法会变成事实政策, 反噬组织。
- 直接复制粘贴别家政策/手册 → 不契合本组织规模、文化与法律环境。
- 在手册里写死"强制两周提前通知否则禁再雇佣" → 破坏 at-will。
- 等严重问题出现才开始补写记录 → 补记不可信、无法律价值。

### 方法论局限 / 适用边界

- **美国法律语境**: at-will 声明、TIPS、NLRA 均为美国制度, 非美国读者不可直接套用; 各州对 at-will 例外差异极大。
- **预设组织有 HR 支撑**: 写文档、做手册法律审阅、维护签收回执都隐含成型的 HR 部门与预算; 对无 HR 的中小企业/初创, 至少要有一个明确责任人并引入法律审阅, 否则这些"护城河"建不起来。
- **预设"最佳实践"放之四海**: 大公司手册模板对初创是空中楼阁; 方法也提醒警惕复制粘贴, 但整体仍偏 Fortune 500 语境。
- **雇主视角**: 文档纪律的服务对象被预设为"组织防御", 未充分讨论员工查阅自己记录的权益与边界。

### 容易混淆的邻近方法论

- **corrective discipline vs PIP**: 行为问题走纪律阶梯, 绩效问题走 PIP, 二者是两条独立轨道但可并行。
- **TIPS vs "工会期间最好闭嘴"**: TIPS 是"四不", 不是禁言令; 如实答问题、直白讲政策、听自愿信息是合法的, 别因噎废食。
- **文档记录 vs 调查记录**: 前者是持续的日常纪律, 后者是事实存疑时的主动查证, 目的与流程不同。

## 快速理解: 5 个示例问题

用这 5 个最常被问到的场景快速上手本 skill, 每个问题都对应它真正触发的处理动作:

1. **公司没有员工手册, 怎么建? 要包含哪些内容?** — 手册四件套 (at-will/量体裁衣/签字/更新再签) + 10 大板块
2. **员工总迟到、还旷工, 书面警告怎么写? 从哪一级开始?** — 纠正式纪律阶梯 (按严重度定起点)
3. **工会开始组织活动, 经理现在能对员工说什么、不能说什么?** — TIPS 四不 (威胁/盘问/许诺/监视) + Do/Don'ts
4. **出事了才发现平时没记录, 现在补写行吗? 怎么写?** — 判停: 事后补记不可信, 只从今天起记
5. **员工绩效差还顶撞主管, 写书面警告还是给 PIP?** — 行为 vs 绩效二分
