# 终止与裁员 — 解雇和裁员的执行纪律

## R — 核心要旨 (Reading)

终止雇佣先分两类: 自愿终止是员工主动发起 (退休或辞职); 非自愿终止是组织发起, 如因故解雇 (通常伴随有过错行为、常是纪律流程的一步) 或裁员 (因业务损失或并购导致的职位削减), 也包括临时任务到期、假期到期等情形。

---

## I — 方法论骨架 (Interpretation)

解雇与裁员是人事领域风险最高、最常被搞砸、最伤人的动作, 因而要像面试一样认真准备。骨架是四条并行的纪律: (1) 先给"员工离开"正确分类——是员工主动 (辞职/退休) 还是组织主动; 组织主动里又分因故 (纪律链条的末端) 与裁员 (职位消失)。分类决定后面走哪条路径, 选错类型 (如把因故伪装成裁员) 当场穿帮并招致法律挑战。(2) 因故解雇走证据纪律——动手前穷尽事实 (违规是否成立且严重、先例怎么处理、员工绩效史、有无法律要求、投诉是否已彻查), 用证据三分法盘点 (文档/佐证/间接), 只把"事实"而非"推断"作为依据, 并逐项过解雇检查清单; 任何员工都不应被草率解雇。(3) 裁员走客观标准——裁的是"职位"不是"人", 禁止用裁前突击打差评等主观理由塞人, 并在律师-客户特权下做不利影响分析, 核对 WARN 通知义务与 OWBPA 豁免程序。(4) 执行与善后——终止会议双人出席、中性私密场地、座位防堵门、提前演练脚本, 覆盖决定/理由/生效日/福利/交接; 离职后守反报复红线 (视同未投诉), 辞职文件请求而非强制, "以辞职代替解雇"要么全员要么不给。

## A1 — 应用案例 (Past Application)

### 案例 1: "只能因盗窃或骚扰解雇?"——一位高管的误解
- **问题**: 一位资深高管坚称"解雇一个人的唯一理由只有盗窃或骚扰, 我想不出别的", 围绕如何处置一个员工问题陷入了争论。
- **方法论的使用**: HR 高管用终止类型学拆解这场争论——自愿离职 (辞职/退休) 与非自愿离职 (因故/裁员/行政) 的区分, 并按真实性质归类。
- **结论**: 解雇的理由远不止盗窃/骚扰; 关键是正确分类, 分类决定流程与文档路径。
- **结果**: 会议从"能不能开"转向"按哪类终止、怎么体面执行", 争议化解。

### 案例 2: "以辞职代替因故解雇"对女性的不利影响
- **问题**: 组织想给部分员工"体面退路", 允许他们以辞职代替因故解雇——只要他们主动开口求这个选项。
- **方法论的使用**: 用不利影响 (adverse impact) 逻辑检验这个"人情选项": 若男性更常开口索要, 则女性表面上被解雇的频率就会显得更高。
- **结论**: 表面人性化的选择性施舍反而制造统计性歧视; 规则是"要么对所有人开放, 要么一个都不给"。
- **结果**: 揭示"善意灰色操作"的法律后果, 组织被引导走正规的因故解雇或全员一致程序。

### 案例 3: 群体裁员时的 OWBPA 豁免最低标准
- **问题**: 组织要对一批 40 岁以上员工做群体裁员并让他们签豁免/遣散协议, 担心豁免被认定无效。
- **方法论的使用**: 对照 ADEA/OWBPA 的最低程序要件: 书面且可理解、明确指向 ADEA 权利、不豁免未来权利、须有对价、书面建议咨询律师、至少 21 天考虑期 + 7 天撤销期 (群体裁员 45 天)。
- **结论**: 豁免"明知且自愿"有硬性的程序门槛, 最常失效点是考虑期不足与未书面建议咨询律师。
- **结果**: 把遣散协议设计成可辩护的合规程序, 数字须在使用前核对现行法条。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 员工绩效/行为出问题, 经理想直接"开了", 或问"这次解雇能站得住吗"。
2. 公司要裁员 (RIF / 部门重组), 需要确定名单并合法执行。
3. 需要执行解雇/裁员面谈, 不确定会议怎么开、谁在场、说什么。
4. 员工主动提出"我辞职, 就当你们没开除我", 或需要处理辞职信/离职交接。
5. 离职后出现争议 (失业金申诉、诉讼、报复指控), 需要复盘与应对。

### 语言信号 (用户的话里出现这些就应激活)

- "想开除 / 开了 / 炒了 / 裁掉 / 让 TA 走 / 终止雇佣"、"fire / terminate / lay off / RIF / let someone go / get rid of someone"
- "怎么定裁员名单才不违法?"、"layoff list / severance / 遣散 / COBRA / WARN"
- "解雇面谈怎么开?"、"termination meeting / 双人出席"
- "他说辞职就当没被开除, 能答应吗?"、"resign in lieu of termination"
- "我们已经赢了官司, 但后来处分了他, 会有事吗?" (报复风险)

### 与相邻 skill 的区分

- 与 `documentation-and-policies` 的区别: 文档 skill **生产**证据 (平时的事发即记、事实非推断、手册/纪律流程), 终止 skill **消费**证据 (解雇决策与会议执行)。经理要开除人却没有任何记录 → 先回文档 skill 建立记录纪律, 再谈终止; 事后补记不可信。
- 与 `performance-management` 的区别: PIP 是"改进之路"而非解雇前奏; 绩效问题先走绩效管理, 只有穷尽改进、确实是行为/绩效硬伤后才进入因故解雇。
- 与 `employment-law-basics` 的区别: 后者是通用法律地基 (at-will、歧视双理论); 终止 skill 是解雇/裁员的具体执行程序 (分类、证据、会议、善后)。
- 与 `benefits-and-leave` 的区别: WARN/COBRA 术语在那展开; 终止 skill 只把它们作为终止会议/裁员执行的要点引用, 不做福利制度设计。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **分类终止类型**
   - 判断是自愿 (辞职/退休) 还是非自愿; 非自愿再细分 for-cause (纪律链条末端) / layoff (职位消失) / 行政 (临时任务/假期到期)。
   - 完成标准: 明确写出"属于哪一类 + 两条理由", 且理由基于事实而非感觉。
   - 判停条件: 若本质是绩效差距且尚未走绩效/纪律流程 → 停止, 回到 `performance-management` 的 PIP 路径, 并先去 `documentation-and-policies` 补齐记录, 不要进入解雇。

2. **for-cause 路径: 穷尽事实 + 证据纪律**
   - 逐项回答: 违规是否成立且严重? 公司过往怎么处理同类 (先例)? 员工工龄与绩效史? 有无法律要求? 相关指控是否已彻查? 用证据三分法盘点 (文档/佐证/间接); 把"事实"与"推断"分开, 只以事实为据; 过 13 问解雇检查清单 (事实证据过硬吗/沟通了吗/文档化了吗/一视同仁吗/可能违法吗/有替代方案吗/能辩护吗)。
   - 完成标准: 清单每一问都有书面答案, 事实与推断分列, 证据类型逐项标注。
   - 判停条件: 任一问证据不足、与先例不一致, 或只能靠"推断"支撑 → 暂停, 先补文档或放弃本次解雇; 严禁用裁前突击打差评来凑数。

3. **layoff 路径: 裁职位不裁人 + 不利影响分析**
   - 用客观标准 (组织未来所需 KSA、岗位必要性、职能/重叠度) 确定哪些**职位**被削减, 而非挑"人"; 名单确定后在律师-客户特权下做 adverse impact 分析; 核对 WARN (100+ 员工 / 50 人或占 33% / 500 人 → 提前 60 日历日通知); 若需 40+ 员工签豁免, 过 OWBPA 要件 (21/45 天考虑期 + 7 天撤销 + 书面建议咨询律师)。
   - 完成标准: 名单全部由职位标准导出且无个人绩效/好恶掺入; 不利影响分析通过或差异已解释; WARN/OWBPA 的数字按当前法条核对过。
   - 判停条件: 若不利影响分析显示某受保护群体被不成比例波及 → 回到职位标准重新定名单, 不得带病执行。

4. **终止会议: 提前彩排 + 安全执行**
   - 直属主管 + HR 双人出席; 中性私密场地; 座位安排让情绪失控者无法堵住出口; 提前成文脚本: 决定已作出 → 理由与关键事实 → 生效日期 → 最后薪资/遣散/COBRA/失业金/再就业安置 → 交接与联系人; 会后即刻清空工位、归还资产、护送出楼, 不现场辩论。
   - 完成标准: 脚本成文且双人时间/场地/福利清单都已确认; 若为裁员, 按脚本先讲业务背景再讲"你的职位被裁撤", 并给情绪缓冲。
   - 判停条件: 若现场出现人身安全风险 → 立即中止并启用安保/疏导预案。

5. **离职后纪律: 反报复 + 文档归档**
   - 员工投诉后"视同未投诉"对待, 不因投诉解雇/降级/边缘化/威胁/扩散 (报复是独立违法, 即使原投诉无据); 辞职信"请求"而非"强制"; "以辞职代替解雇"要么全员要么不给; 离职面谈数据看趋势不看个案。
   - 完成标准: 离职后 60-90 天无任何可被解读为报复的动作; 辞职信/离职通知/交接清单已签名归档; 离场数据已按团队/时段/主题聚合备查。
   - 判停条件: 若接到歧视/报复指控 → 停止一切涉该员工的管理动作, 上报 HR/法务按调查流程处理。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 员工只是绩效未达标且未走 PIP/改进流程 → 用 `performance-management`, 先改进后谈解雇。
- 员工正常主动辞职、无争议 → 走 offboarding/交接流程, 不需要解雇程序。
- 无 HR/法务支撑的个体创业者想直接照抄美国法律数字 (WARN/OWBPA/COBRA) → 数字随法规修订会变, 必须核实当前法条并咨询律师。

### 常见失败模式

- 把"强制提前两周通知/否则禁再雇佣"写进手册 → 破坏 at-will, 反而给自己套枷锁。
- 用裁前突击负面绩效评价把人塞进裁员名单 → 主观标准, 为歧视诉讼留把柄。
- 只给一部分人"以辞职代替解雇" → 对另一群体制造不利影响。
- 把因故解雇伪装成裁员 → 职位还在/立刻补员, 谎言当场穿帮。
- 赢了歧视官司却在事后报复 → 追加报复指控, 把赢的案子输回去。
- 拿单个离职访谈的评论就急着重写政策 → 样本不足, 应看趋势。

### 方法论局限 / 适用边界

- **美国法律语境**: WARN、OWBPA、COBRA 均为美国联邦法, 对非美国读者基本不可直接套用; 即使在美国境内各州差异也极大。
- **数字与阈值会变**: WARN 的 60 天/100 人、OWBPA 的 21/45 天、COBRA 的 2% 管理费等都随时随法规修订而变, 使用前必须核对现行法条。
- **预设组织有 HR 支撑**: "主管 + HR 双人出席"在无专职 HR 的小公司不可行; 至少要安排一名独立见证人, 并把证据纪律的权重提得更高。
- **雇主视角**: 整体从管理与法律防御角度写作, 未充分处理被解雇者一方的处境与权力不对等; "体面"是法律风险视角的产物而非共情视角。

### 容易混淆的邻近方法论

- **PIP vs 解雇**: PIP 是改进之路 (performance-management), 把它当解雇前奏是常见误用。
- **corrective discipline 阶梯 vs 因故解雇**: 纪律阶梯 (口头→书面→最终→停职→解雇) 是行为问题的处置链条, 因故解雇多为该链条末端; 别跳过过程直接解雇, 也别把"绩效"问题硬塞进纪律轨道。
- **adverse impact vs disparate treatment**: 裁员审的是前者 (中立规则却产生群体性不利), 不是逐案的故意歧视; 两者证据要求不同。

## 快速理解: 5 个示例问题

用这 5 个最常被问到的场景快速上手本 skill, 每个问题都对应它真正触发的处理动作:

1. **想开除一个员工, 怎么开才不违法、不被告?** — 终止分类 → for-cause 走证据纪律
2. **公司要裁员, 名单怎么定才合法?** — 裁职位不裁人 + 不利影响分析 + WARN/OWBPA
3. **解雇面谈怎么开? 谁在场、说什么、在哪谈?** — 终止会议脚本 (双人/中性场地/防堵门/彩排)
4. **员工说'我辞职, 就当你们没开除我', 能答应吗?** — 以辞职代替解雇: 要么全员要么不给, 防不利影响
5. **员工绩效差 + 顶撞主管, 想直接开掉。** — 先分类; 证据不足则判停回绩效/文档
