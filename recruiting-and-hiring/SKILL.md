# Recruiting and Hiring — 招聘与录用决策

## R — 核心要旨 (Reading)

录用建议采用行为面试法, 其前提是: 过去经验是未来行为的最佳预测。让候选人讲述情境 (Situation)、为完成任务采取的行动 (Action) 与结果 (Result), 用可验证的过去行为做录用决策。

---

## I — 方法论骨架 (Interpretation)

招聘不是"看简历—聊一聊—拍板"的事件, 而是一条从岗位定义到 offer 的完整管道。起点不是发招聘广告, 而是先把"这个职位要什么、两年后怎么算成功"想清楚: 用职位描述和对现有优秀员工的访谈, 把岗位拆成"必备(required)"和"加分(desired)"两层, 每一条都能被证书/经历/背调验证。

面试环节用行为证据代替印象: 只问能说明工作关联的问题, 不向候选人泄露录用标准; 用 STAR 索取候选人过去真实发生的故事, 多个面试官用评分表独立打分, 并对照清单警惕六种评分偏差(首因、对比、晕轮、叉子、盲点、假定资质)。录用前先做内部 vs 外部招聘的显式权衡, 再完成背景核查。

决策时绝不妥协——坏招聘的成本远超空岗。最后把决定闭环: 书面 offer 写清薪资周期、exempt 状态、条件性条款与 at-will 声明, 落选者收到个性化的拒绝信。

## A1 — 应用案例 (Past Application)

### 案例 1: 西南航空 "为态度而招, 为技能而训"
- **问题**: 空乘这类高触达、高频对客的岗位, 决定体验的不是可培训的知识, 而是难以改变的待人态度; 传统的"看学历/看技能"筛选选不出对的人。
- **方法论的使用**: 案例用"hire for attitude, train for skill"重设筛选优先级——把招聘资源集中在不可教的维度(态度), 把可教的维度(服务技能)交给培训。
- **结论**: 态度几乎不可教、技能相对易学; 所以对可培训岗位, 态度/价值观排在现成技能之前。
- **结果**: 西南航空把这一哲学贯彻到品牌——空乘被鼓励用歌/说唱/幽默演绎 FAA 安全广播, 乘客反而更愿意听, 形成无法复制的文化招牌。

### 案例 2: Zappos 坏招聘的代价
- **问题**: 招聘拖太久, 业务方催"差不多就定了吧"; 录用第三顺位候选人看似止损。
- **方法论的使用**: 用"宁缺毋滥"与坏招聘成本公式对抗妥协压力: 坏招聘不止是解雇费用, 而是对组织文化长期的侵蚀。
- **结论**: no hire is better than a bad hire——空位是机会成本, 错人是复合成本。
- **结果**: Tony Hsieh 估计坏招聘让 Zappos 损失超过 1 亿美元, 且影响在辞退后长期残留; 这个论证成为守住录用标准的依据。

### 案例 3: HR 经理岗位 Required/Desired 技能清单
- **问题**: 一个岗位"要什么样的人", 常被写成"有经验、负责任"这类无法筛选的话。
- **方法论的使用**: 用 required/desired 两层结构把"找谁"转成"能验证的标准": required 放不可妥协的硬门槛(证书、年限、团队规模、系统熟练度), desired 放加分项。
- **结论**: 每一条都要能被证书/经历/背调验证, 避免无法验证的软描述。
- **结果**: 产出一份可直接用于筛选、面试与背调的岗位画像模板。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 岗位空缺, 但面试官对"什么叫优秀"各执一词——先统一成功标准再面试。
2. 用户要准备面试, 需要行为面试题库, 或担心问出非法/歧视性问题。
3. 用户纠结: 内部提拔 vs 外部招聘, 或该不该妥协录用次优者。
4. 用户要发 offer / 拒绝信, 需要话术与书面模板(口头 offer → 书面确认)。
5. 用户对背景核查的合法性与文档化有疑问。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么招/招人/面试/候选/要不要录/offer/拒绝信/背调"
- "how to hire / interview / candidate / make an offer / reject / background check / bad hire"

### 与相邻 skill 的区分

- 与 `workforce-planning` 的区别: 规划回答"要不要招、招多少", 本 skill 回答"具体招谁、怎么选"; 规划问题出现在"缺人"之前。
- 与 `job-analysis-and-ada` 的区别: 职位分析定义"这个职位到底要什么"(essential functions / ADA 合理便利), 本 skill 消费其产出做筛选录用。
- 与 `onboarding` 的区别: 本 skill 止于 offer 发出 + 拒绝信; 报到后的前 90 天流程归 onboarding。
- 与 `employment-law-basics` 的区别: 法律地基是"必须懂的红线", 本 skill 是"执行的漏斗"; 非法面试题等红线在下方 B 段给出。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定义岗位与成功标准(回到漏斗起点)**
   - 用职位描述 + 对现有明星员工的访谈, 产出 required/desired 技能清单, 并写出一句"两年后此人算成功"的可验证标准。
   - 完成标准: 清单每条可被证书/经历/背调验证; 团队对"成功长什么样"达成一致。

2. **结构化行为面试与评分**
   - 用同一组 STAR 问题覆盖所有候选人; 每题自检"能否说明工作关联"且不向候选人泄露录用标准; 多面试官用评分表独立打分, 对照六种偏差复核。
   - 完成标准: 每位候选人被问同一组问题; 每场面试留下可追溯的评分表。
   - 判停条件: 若发现岗位定义与实际需求不符, 或关键 required 项无人满足, 回到步骤 1 重新定义, 而不是降标妥协。

3. **录用决策与闭环**
   - 先做内部/外部招聘权衡; 汇总评分做证据驱动决定。通过者: 背景核查 + 书面 offer(写明薪资周期、exempt 状态、条件性条款、at-will 声明、有效期)。落选者: 个性化拒绝信。
   - 完成标准: offer 全部书面化并获候选人确认; 每个落选者收到个性化通知; 背调结果文档化存档。
   - 判停条件: 若背调发现 required 硬条件不实, 撤回或重评 offer, 不进入入职流程。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只是问某条法律条文/阈值(见 `employment-law-basics`; 且美国阈值会随法规变)。
- 用户在设计招聘广告、雇主品牌文案或薪酬待遇(见 `compensation-and-pay-equity`)。
- 用户要处理的是员工离职、解雇、裁员(见 `termination-and-layoff`)。
- 用户已有人选、只想要一份"入职 checklist"(见 `onboarding`)。

### 常见失败模式

- **六种评分偏差**导致录用偏离真实岗位匹配: 首因、对比、晕轮、叉子、盲点、假定资质; 用结构化问题 + 多人评分 + 各面试官不同聚焦主题中和。
- **妥协录用第三顺位**: 坏招聘成本(薪资 + 文化毒化 + 好员工流失)远超空岗的机会成本。
- **非法面试题与歧视性备注**: 只问能说明工作关联的问题; 申请表/简历上的"金发美女"式备注可能被法庭传唤, 辩诉成本数十万美元。
- **提前泄露录用标准**: 候选人会投其所好编造答案, 你拿不到真实信息。

### 方法论局限 / 适用边界

- 整体为美国法律语境(Title VII / at-will / 各州差异极大), 非美国读者不能直接套用; 面试题"合法与否"的判断要替换为当地法律。
- 假设组织有成型 HR、训练有素的面试官、背调预算——小团队/初创往往不具备, 需简化但保留核心纪律。
- "最佳实践"未讨论组织规模、行业、文化的权变。
- 深层张力: 再完美的清单也堆不出好管理者; 合规导向流程若被机械执行, 反而催生避险、官僚的管理风格。

### 容易混淆的邻近方法论

- **STAR 行为面试 vs 情境/假设性面试**("你会怎么做")——后者得到的都是排练好的答案。
- **面试六种评分偏差 vs 绩效评审七种评分偏差**——机制相似(光环/对比/首因), 但应用场景不同(选人 vs 评人)。

## 快速理解: 5 个示例问题

用这 5 个最常被问到的场景快速上手本 skill, 每个问题都对应它真正触发的处理动作:

1. **两个候选人都不错, 录哪个? 有没有行为面试题可参考?** — STAR 行为面试 + 结构化评分
2. **招聘拖太久了, 业务催着'差不多就定了吧', 要不要录第三顺位?** — 宁缺毋滥 + 坏招聘成本
3. **想给候选人和落选者发通知, 有没有 offer 和拒绝信模板话术?** — 书面 offer + 个性化拒绝信
4. **背景核查怎么做才合法? 要查些什么?** — 可文档化的背调流程
5. **内部有个合适的人想转岗到这个空缺, 要不要先内部提拔再外招?** — 内外部权衡: 先评估内部再外招
