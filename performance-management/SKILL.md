# 绩效管理 (Performance Management)

## R — 核心要旨 (Reading)

无论采用何种模式, 绩效管理都必须照顾到若干要素——设定目标、评估绩效、提供反馈、文档与数据、为未来绩效蓄能。它要求对每位员工保持持续关注, 因此它是一个"过程", 而不是一个"事件"。

---

## I — 方法论骨架 (Interpretation)

绩效管理是一个全年运转的闭环, 而不是年末的一次打分:

1. **对齐目标**: 目标从组织→团队→个人逐级对齐, 用 SMART 写清, 建议季度复盘校准。
2. **评估与反馈**: 对照职位要求与目标, 用可衡量、与工作相关、可辩护的标准评估; 反馈是双向、频繁、具体的, 可用"发生了什么 → 为何重要 → 下一步做什么"三段结构把对话从"给评语"变成"共创行动"。
3. **文档化**: 绩效表现与关于绩效的对话, 正负面都要随时记, 只记事实不记推断——这是加薪、晋升、解雇一切未来管理决策的证据基础。
4. **处理差距**: 在下结论前先排查管理/资源/培训/同事/生活等环境因素, 再归责员工; 确属绩效差距就制定 PIP——3-5 项任务, 每项含任务定义、行动与度量、完成日期; PIP 的终点是改进成功, 不是辞退。
5. **指向未来**: 评审不止评过去, 要为员工的下一个台阶积蓄能力。

读完以上要点, 应能理解: 绩效管理 = 目标 × 反馈 × 文档 的持续过程, 且"差距先归因、PIP 是改进之路"是其两个反直觉要点。

## A1 — 应用案例 (Past Application)

### 案例 1: Deloitte 2015 绩效改革——4 个前瞻问题替代评分表
- **问题**: 传统年度评分表"翻旧账", 只评过去, 无法驱动未来绩效。
- **方法论的使用**: 案例引用 Deloitte 的改革, 转向实时反馈与前瞻导向——用 4 个未来导向问题 (若花我的钱, 是否给这位员工最高加薪 / 我是否全力留他 / 他是否高风险 / 他今天能否晋升) 替代年度评分表。
- **结论**: 绩效管理可以更敏捷、更个性化; 反馈的落点是"未来该做什么", 而非"过去值几分"。
- **结果**: 案例成为全行业绩效改革中被反复引用的标志, 案例以它论证"过程而非事件"的骨架不变。

### 案例 2: PIP 是"改进之路"不是"开除之路"
- **问题**: 经理把 PIP 当辞退前奏, 问 HR "员工完成全部任务怎么办"。
- **方法论的使用**: HR 用 PIP 的正确定位回应——PIP 含 3-5 项任务, 每项有任务定义、行动方案与衡量、完成日期; 完成计划本身就是目标。
- **结论**: PIP 是通向改进的路, 不是通向解雇的路。
- **结果**: 若员工完成全部任务, 就是成功, 不是意外。

### 案例 3: 全年好评的解雇黑洞
- **问题**: 经理想以绩效差解雇员工, 但最近一次年度评审全是好评, 拿不出任何负面记录。
- **方法论的使用**: 方法指出"绩效评审本应为未来管理决策提供文档依据", 文档必须在全年随事件发生持续记录, 正负面与绩效对话都要记, 且只写事实不写推断。
- **结论**: 好评满屏却想以绩效解雇, 是文档缺失的典型灾难。
- **结果**: 解雇既不公平也难获法律支持——文档必须"事发即记"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设定/校准绩效目标, 要把个人目标与团队、组织对齐, 想写成 SMART 标准。
2. 做绩效面谈或日常 check-in, 尤其要谈负面反馈, 怕谈崩、谈僵、谈不出行动。
3. 写绩效评审, 担心评分主观、有偏差、不可辩护、被员工质疑。
4. 下属持续不达标, 纠结直接开人还是给机会、怎么留证据、该不该用 PIP; 或绩效不达标但疑似态度/故意不配合, 需要先归因区分绩效差距 (走 PIP) 与行为问题 (转纪律), 混合情形可并行处置。
5. 公司想从年度评审改成持续反馈模式, 要确认哪些要素不能丢。

### 与相邻 skill 的区分

- 与 `development-and-coaching` 的区别: 绩效管理管**当下的职责是否达标、怎么改进**; 发展与教练管**未来的能力拓展与成长路径**。PIP 解决当下绩效差距; 教练服务高潜者的主动发展——教练不是修理工具, "修好他"式请求应回到绩效管理处理。
- 与 `termination-and-layoff` 的区别: 本 skill 到"文档齐备、差距已按程序处理"为止; 若决定解雇, 面谈脚本、终止类型分类、不利影响分析由 termination skill 接管。
- 与 `harassment-and-investigation` 的区别: 行为问题 (不恰当举止) 走纠正式纪律, 与绩效问题 (完不成任务) 用不同工具; 涉嫌骚扰的行为按骚扰判定与调查流程处理, 不走 PIP。
- 与 `documentation-and-policies` 的区别: 绩效文档是本 skill 闭环的要素之一, 但行为纪律 (纠正式纪律阶梯) 与手册/政策维护在其 skill; PIP 解决绩效差距, 纪律解决行为问题, 两条轨道。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **对齐目标与标准**
   - 完成标准: 每位员工有书面目标, 用 SMART 表述, 已与团队/组织对齐并留有记录; 有明确的季度复盘时间点。

2. **全年反馈与文档**
   - 完成标准: 按"What → So What → Now What"完成至少一次双向反馈并留痕; 事件日志含时间/地点/具体行为, 正负面都记、只写事实; 与员工的绩效对话已记录。
   - 判停条件: 若反馈暴露的纯属"不恰当举止"且无任何绩效差距成分 (如纯迟到/冲突/顶撞), 跳到行为纪律流程 (纠正式纪律, 不在本 skill); 若绩效不达标伴随疑似态度/行为问题, 先继续到第 3 步做归因区分, 不要提前跳转。

3. **差距归因与 PIP**
   - 完成标准: 对每个差距走完归因清单 (管理/资源/培训/同事/生活) 并记录结论; 疑似态度/故意不配合时先归因区分——确属绩效差距则产出含 3-5 项任务 (定义 + 行动与度量 + 完成日期) 的 PIP, 明确定性为"改进之路"; 纯行为问题移交纠正式纪律; 混合情形并行处置 (PIP + 纪律, 行为部分由纪律流程记录); 若差距源于组织侧能力/资源缺失, 先修组织侧而非归责员工。

4. **评审与指向未来**
   - 完成标准: 评审用可辩护标准 (客观、与工作相关、不提受保护特征) 并防七种评分偏差 (光环/关键事件/对比/相似于我/首因近因/过去锚定/趋中); 每份评审结尾含"下一步发展/改进"的具体动作项。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 行为纪律问题 (迟到、冲突、暴力、盗窃)——走纠正式纪律阶梯, PIP 不适用。
- 纯薪酬/晋升定级决策——那是薪酬与内部流动的领域。
- 已决定解雇后的执行——面谈脚本与不利影响分析在 termination skill。
- 用户只是要一份"绩效考核表/要素库"的格式参考——那是样张素材, 不是方法论调用。

### 常见失败模式

- **只写好评, 解雇时无档可用**: 年度评审通篇好评, 却要以绩效为由解雇时拿不出任何负面记录——评审必须与持续记录配套。
- **把 PIP 当解雇前奏**: 先给 PIP 再找借口走人——PIP 就是改进之路; 员工完成全部任务不是"意外", 而是目标达成。

### 方法论局限 / 适用边界

- 评审"可辩护性"基于美国反歧视法 (不提受保护特征、跨评分者一致性); 非美国语境与各州差异需另行确认。
- 假设组织有成型的 HR 体系、政策与文档基础设施; 对小团队/初创, 可先用手写事件日志起步, 不必等完美系统。
- 最强反对: 过程化方法论与方法引用的 Gallup 证据 (最伟大的经理"打破所有规则", 聚焦信任与优势) 存在张力——流程只是骨架, 信任与优势才是血肉; 别让合规导向催生避险、官僚的管理风格。
- 代际本质主义: 不要给"千禧一代"等群体贴"需要特殊管理"的标签。

### 容易混淆的邻近方法论

- **PIP vs 纠正式纪律**: 绩效问题 (完不成任务) 用 PIP; 行为问题 (不恰当举止) 用纪律 (绩效 vs 行为二分)。
- **绩效评审 vs 薪酬定级**: 评审是证据与对话, 定级把评审结果连到薪酬带宽与 compa-ratio。
- **反馈对话 vs 教练对话**: 反馈直接评价与纠偏; 教练不提供建议、不评估, 引导客户自己定议程。

## 快速理解: 5 个示例问题

用这 5 个最常被问到的场景快速上手本 skill, 每个问题都对应它真正触发的处理动作:

1. **下属持续不达标, 直接开人还是先给改进机会? 怎么留证据?** — 差距归因 → PIP (改进之路而非辞退前奏)
2. **绩效面谈要谈负面反馈, 怎么说才不僵?** — What → So What → Now What 结构
3. **怎么写绩效评审才可辩护、不被员工质疑主观?** — 可辩护标准 + 防七种评分偏差 + 全年文档
4. **PIP 该怎么设计? 要包含哪些内容?** — 3-5 项任务: 定义 + 行动与度量 + 完成日期
5. **员工绩效不达标, 但表现更像态度问题、故意不配合, 怎么办?** — 先归因区分: 绩效差距走 PIP, 行为走纪律, 混合并行
