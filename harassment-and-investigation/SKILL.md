# 反骚扰与调查 (Workplace Harassment & Investigation)

## R — 核心要旨 (Reading)

调查是以得出结论为目的、对事实所做的系统性查究与核验; 事实有争议, 就调查。选对调查人, 识别相关政策与证人, 保全包括电子在内的一切相关文件, 尽可能保密, 并把调查过程书面记录下来。

---

## I — 方法论骨架 (Interpretation)

反骚扰是一条"判定 → 行动 → 调查 → 预防"的链路:

1. **判定**: 先二分——交换条件式 (quid pro quo: 性利益交换雇佣条件, 多为有权者) 还是敌意环境式 (hostile environment: 行为不受欢迎 + 普遍或严重, 二选一即可, 可基于性别/种族/宗教/年龄等任一受保护特征)。再用双标准校准: 法律采**影响重于意图** (本意玩笑不免责); 用"与指控方同类的理性人是否会觉得冒犯"排除主观歪曲。
2. **行动**: 知情即行动——管理者看到或听到不当行为就有义务采取行动; "没有正式投诉"不构成免责 (知道或应当知道即担责; 管理者本人是骚扰者时组织负绝对责任)。员工说"别声张、我自己会处理"不是选项。
3. **调查**: 事实存疑即调查——选对调查人 (不带偏见, 必要时法务或外部), 识别政策与证人, 保全电子与纸质证据, 尽量保密, 全程文档化; 调查是流程, 不是表演。
4. **预防**: 滑坡预警——微冒犯被容忍会恶化成正式骚扰, 要抬高"尊重标准"、对早期苗头立即干预, 配旁观者干预培训 (人越多越没人管的效应需要训练逆转)。全程反报复: 对投诉人"如同未投诉一样"对待。

读完以上要点, 应能理解: 骚扰判定看客观影响而非意图, 组织知情即担责, 调查有固定流程且不可因"当事人不愿"而跳过。

## A1 — 应用案例 (Past Application)

### 案例 1: Faragher / Ellerth (1998) 雇主骚扰责任标准
- **问题**: 雇主能否用"没人正式投诉"来免除骚扰责任?
- **方法论的使用**: 案例引用最高院判例确立责任标准——雇主知道或应当知道行为而未纠正即须担责; 管理者本人是骚扰者时组织负绝对责任; 救济含欠薪与惩罚性/补偿性赔偿。
- **结论**: 正式投诉不是免责前提; 组织必须主动识别与纠正。
- **结果**: 判例成为反骚扰法律护栏的核心, 直接支撑"知情即行动"原则。

### 案例 2: #MeToo / The Silence Breakers
- **问题**: 敌意环境型骚扰普遍而隐蔽, 受害者因怕报复、怕丢工作而沉默。
- **方法论的使用**: 案例以 Ashley Judd 公开指控 Weinstein 引爆的 #MeToo 说明"沉默 ≠ 没有骚扰"。
- **结论**: 举报率低不能当安全信号, 要靠预防性培训、旁观者干预与反报复保障降低"沉默成本"。
- **结果**: 事件推动组织重新审视预防机制的必要性。

### 案例 3: 反歧视与骚扰预防提示
- **问题**: 如何在骚扰发生前系统性预防。
- **方法论的使用**: 方法给出预防清单——客观决策不考量受保护身份、避免假设与刻板印象、例会传达政策、密切观察并迅速处理不当行为; 员工要求保密时明确告知"这不是选项, 组织知情必须调查"。
- **结论**: 知情即调查是不可协商的义务, "尊重当事人意愿"不是合法选项。
- **结果**: 预防清单成为反骚扰管理的操作指南。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 收到骚扰/歧视投诉, 或目击/听说了不当行为 (尤其没有正式投诉但有见闻)。
2. 员工请求"别声张、我自己会处理", 管理者犹豫要不要上报。
3. 判断某个玩笑/行为/同事间摩擦是否够得上骚扰, 或面对"我只是开玩笑"的辩解——即便最终判定为一般人际摩擦, 判定动作本身也发生在本 skill (先判定是否够"不受欢迎 + 普遍或严重"门槛, 不够再转纪律/沟通)。
4. 要启动/参与职场调查, 或评估一次已做过的调查是否合格。
5. 设计反骚扰培训/预防 (尊重标准、旁观者干预)。

### 与相邻 skill 的区分

- 与 `termination-and-layoff` 的区别: 调查结论可能指向解雇 (骚扰者被处分), 但本 skill 管**判定 + 调查 + 预防**; 终止面谈脚本、终止类型分类、不利影响分析由 termination skill 接管——调查结束、证据齐备即移交。
- 与 `performance-management` 的区别: 骚扰是特定类型的严重行为问题, 不走 PIP; 若同时存在绩效与行为问题可并行处置 (PIP + 纪律), 但骚扰本身的判定与调查在本 skill。
- 与 `documentation-and-policies` 的区别: 调查依赖文档纪律 (事实 vs 推断、事发即记), 但文档化 skill 管日常记录与员工手册, 本 skill 管骚扰的专门判定标准与调查程序。
- 与 `employment-law-basics` 的区别: 骚扰的法定形态是法律内容, 本 skill 是应用层——把判定标准接到行动/调查/预防动作上。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判定**
   - 完成标准: 输出二分判定 (quid pro quo / hostile environment) + 双标准校验 (影响 vs 意图; 与指控方同类的理性人是否觉得冒犯) + 是否满足"不受欢迎 + 普遍或严重"的结论; 判定有书面依据。
   - 判停条件: 若判定为一般不当行为而非骚扰, 转纠正式纪律/绩效流程, 不做正式骚扰调查。

2. **行动与调查**
   - 完成标准: 知情即行动已留痕 (制止/上报记录, 含目击者); 事实存疑即启动调查——调查人确定 (不带偏见, 必要时法务或外部中立第三方), 相关政策/证人清单、电子与纸质证据保全、保密范围、书面调查计划齐备。

3. **预防与闭环**
   - 完成标准: 处理结果与依据反馈给相关方; 对投诉人"如同未投诉一样"对待 (无任何可被解读为报复的动作, 连时间上紧邻投诉的负面处置都要能证明与投诉无关); 落一个预防动作 (尊重标准 / 旁观者干预培训 / 政策传达), 全程文档化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一般人际摩擦/性格冲突——先判断是否够骚扰门槛, 不够就走纪律或沟通流程。
- 纯绩效问题——走绩效管理, 不自动升级为骚扰调查。
- 用户要的是具体法条/判例全文——方法中的美国法律内容有保质期, 以本地律师为准。
- 已定论解雇的执行环节——移交 termination skill。

### 常见失败模式

- **以为"不知道"就能免责**: 知道或应当知道即担责; 管理者本人骚扰时组织负绝对责任。
- **容忍微歧视/微观不尊重**: 翻白眼、插话、看手机等"小动作"被忽视纵容, 会恶化成正式骚扰。
- **指望"人多了自然有人管"**: 旁观者效应恰恰是人越多越没人制止; 干预是可训练的技能。
- **"别声张"不是选项**: 员工说"我自己会处理、请别声张"时, 组织知情即须调查, 不能尊重该请求。

### 方法论局限 / 适用边界

- 判定标准 (quid pro quo / hostile environment / reasonable person) 是美国联邦/州法概念, 各国差异极大; 非美国语境需本地化, 即使在美国各州也随判例演变。
- 法律有"保质期": 责任标准、判例与赔偿额度随时随法规修订而变; 在风险最高处也只能以"咨询你的律师"结尾。
- 默认视角: 方法以 HR/经理视角为默认立场, 对受害者能动性与上下级权力不对等的处理有限; 现实中投诉也可能被滥用, 需双标准 (合理第三人) 防主观歪曲。
- 假设组织有成型 HR 与调查能力; 小团队至少应守住"知情即行动"的底线, 哪怕只记录并上报。

### 容易混淆的邻近方法论

- **hostile environment vs quid pro quo**: 前者无需雇佣利益筹码、同事间也能构成、pervasive 或 severe 二选一; 后者需有权者以性利益交换雇佣条件。
- **影响 vs 意图**: 法律采影响优先, 本意玩笑不免责——不要用"他不是故意的"否定投诉。
- **旁观者干预 vs 举报机制**: 前者教"怎么现场介入" (转移注意/支开一方), 后者是事后渠道; 两者互补不互斥。
- **骚扰调查 vs 一般纪律调查**: 骚扰调查有专门的责任标准 (Faragher/Ellerth) 与取证要求, 不能当普通纪律案处理。

## 快速理解: 5 个示例问题

用这 5 个最常被问到的场景快速上手本 skill, 每个问题都对应它真正触发的处理动作:

1. **有员工举报主管性骚扰, 该怎么调查? 要保全哪些证据?** — 调查流程: 选调查人/保全证据/保密/文档化
2. **员工说'别声张, 我自己会处理', 我能答应吗?** — 知情即行动: 别声张不是选项
3. **同事之间互相开性别玩笑, 算性骚扰吗?** — quid pro quo / hostile environment 二分判定
4. **想设计反骚扰预防培训, 怎么入手?** — 预防清单: 尊重标准/旁观者干预/政策传达
5. **只是同事之间性格不合、互相看不顺眼, 算骚扰吗?** — 先判定门槛, 不足则转纪律/沟通
