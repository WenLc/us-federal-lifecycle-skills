# 福利与休假 (Benefits and Leave)

## R — 核心要旨 (Reading)

法定福利的本质是法律划定的边界, 而不是公司的慷慨。FMLA 为符合条件的员工 (50 人以上雇主、任职满 12 个月且前 12 个月内工作满 1,250 小时) 提供每年最多 12 周的保职位休假; 处理时指定单一沟通渠道、由雇主主动指定 FMLA 并告知权利, 可要求医疗认证, 可预见的治疗可分块休。所有具体数字均为美国语境、随法规变化, 用前必须查证。

---

## I — 方法论骨架 (Interpretation)

法定福利的本质是"法律划定的边界", 不是公司慷慨送的礼物。核心处理框架:

1. **FMLA 休假管理**: 符合条件员工每年最多 12 周"保职位"休假 (军人照护 26 周)。它保的是职位, 不保证带薪。处理时指定**单一沟通渠道** (如 HR), 保证口径与法律一致; 雇主**主动**把休假指定为 FMLA 并告知权利, 可要求主治医师出具医疗认证; 化疗日这类可预见治疗可以**分块休** (intermittent leave)。
2. **COBRA**: 离职等"合格事件"后的受益人可自费延续团体健康险 (雇主+员工全额缴款 + 2% 管理费, 事件后 60 天内选择)。
3. **WARN**: 大裁员前有提前通知义务 (100 人以上雇主, 关厂/大规模裁员前 60 日历日, 有量化触发门槛)。
4. **ERISA**: 1974 年因 Studebaker 养老金破产而立法, 退休金计划由此受联邦监管。

评估任何福利时把它放回**总回报模型**, 并牢记: 员工不知道的福利等于没有价值, 所以透明沟通是落地的一环。

所有具体数字 (12 周、50 人、1250 小时、60 天等) 都是美国语境、随法规变化, 用前必须查证。

## A1 — 应用案例 (Past Application)

### 案例 1: Studebaker 养老金破产 → 1974 ERISA 立法
- **问题**: 1960 年代初, 汽车制造商 Studebaker 关厂, 养老金计划资金严重不足, 无法支付全员养老金。
- **方法论的使用**: 案例用历史链揭示"法律常因灾难事件而推动": 肯尼迪成立委员会调查 → NBC《破碎的承诺》节目曝光 → 国会立法。
- **结论**: 任何靠短期资金池支撑的长期给付承诺都有偿付风险; 福利承诺要当作长期负债看待。
- **结果**: 1974 年《雇员退休收入保障法》(ERISA) 签署生效, 退休金计划自此受联邦监管。

### 案例 2: 1942 工资冻结 + 1943 IRS 免税 → 雇主健康保险的起源
- **问题**: 二战《稳定法》冻结工资, 企业难以用加薪抢人。
- **方法论的使用**: 企业转而用福利竞争人才, 提供慷慨的健康保险; 一年后 IRS 决定对雇主提供的健康保险免税。
- **结论**: 美国"雇主提供医保"模式是历史产物——当初合理, 如今未必; 评估福利要回问"这条制度当初为何而设、现在条件变没变"。
- **结果**: 雇主捆绑式健康保险延续至今; 今天做福利决策要用"员工真实需求 + 组织战略", 而非沿历史惯性。

### 案例 3: FMLA 沟通的单一渠道 (HR)
- **问题**: 员工申请病假照顾家人, 若经理、主管、HR 各说各话, 口径不一, 容易违规则又伤害员工。
- **方法论的使用**: 所有与休 FMLA 员工的联系都走一个指定来源 (如 HR), 保证沟通与政策、法律一致; 雇主主动指定休假性质并告知权利, 要求医疗认证。
- **结论**: 单一渠道 + 主动指定 + 认证要求是 FMLA 合规管理的良好实践。
- **结果**: 沟通口径统一, 员工知晓权利, 休假处理有文档可查。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 员工申请 FMLA/病假/产假/陪产假, 不确定流程怎么走、通知义务是什么
2. 设计或调整福利组合: "该提供哪些保险/弹性福利/休假政策"
3. 处理离职后的 COBRA 延续, 或裁员前的 WARN 通知义务
4. 评估要不要砍某项福利 (学费报销/健身补贴) — 用总回报模型看整体价值
5. 退休金/401k 计划的合规与沟通

### 语言信号 (用户的话里出现这些就应激活)

- "FMLA" / "带薪休假" / "产假" / "陪产假" / "病假" / "COBRA" / "WARN" / "福利" / "保险" / "退休计划" / "401k" / "福利组合" / "福利沟通"
- "FMLA" / "parental leave" / "family medical leave" / "COBRA" / "WARN" / "benefits package" / "health insurance" / "401k" / "ERISA" / "leave policy"

### 与相邻 skill 的区分

- 与 `compensation-and-pay-equity` 的区别: 同属"全面回报", 但本 skill 管间接报酬 (福利/休假, 有法定边界), 薪酬 skill 管直接报酬 (工资/奖金/带宽); 谈薪资结构转走。
- 与 `termination-and-layoff` 的区别: 该 skill 管"如何执行解雇/裁员" (终止会议/证据/不利影响分析); 本 skill 只负责其中的福利延续部分 (FMLA 回岗、COBRA、WARN 通知)。触发点是"福利/休假"而非"解雇执行"。
- 与 `employment-law-basics` 的区别: 该 skill 是通用法律地基 (at-will / 歧视双理论 / 承包二分); 本 skill 聚焦福利与休假这一特定法律域。
- 与 `rewards-and-recognition` 的区别: 福利是制度性、法律约束的间接回报; 认可是非现金、即时的低成本激励。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别法定义务边界**
   - 完成标准: 逐条核对触发条件清单并标注"本组织达标/不达标": FMLA (雇主 50 人/75 英里, 员工 12 个月/1250 小时, 12 周/军人 26 周), COBRA (合格事件/60 天选择窗口/全额+2% 管理费), WARN (100 人以上/关厂或大规模裁员的量化门槛/60 日历日), ERISA (计划文档与披露义务); 每处标注"美国语境, 阈值会变, 用前查证"。
   - 判停条件: 若某员工/情形不满足法定门槛 (如 30 人公司无 FMLA 义务) → 停止套 FMLA, 转查州法与公司政策路径, 别让员工误以为有联邦保护。

2. **休假管理: 单一渠道 + 主动指定 + 认证**
   - 完成标准: 书面 FMLA 流程成立, 唯一联系点 (HR) 明确; 雇主主动把休假指定为 FMLA 并书面告知权利; 医疗认证要求成文; intermittent leave / reduced-schedule 的处理规则写明。

3. **福利设计 + 透明沟通 + 文档化**
   - 完成标准: 福利清单对照员工真实需求 (调查/焦点小组, 参考 rewards-and-recognition 的"先问员工"逻辑); 每项福利有"价值说明"并用总回报语言沟通 (员工不知道的福利 = 没有价值); 雇佣决策 (尤其解雇) 文档化, 以控制失业保险 experience rating 并防推定解雇争议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 非美国语境直接套用 FMLA/COBRA/WARN 的数字与门槛 — 这些是美国联邦/州法, 不通用。
- 单次福利/休假纠纷的诉讼应对 — 那需要咨询律师, 书提供不了可独立站立的答案。
- 解雇/裁员执行流程本身 (终止会议、证据三分、不利影响分析) — 转 termination-and-layoff; 本 skill 只碰其中的福利延续环节。

### 常见失败模式

- **FMLA 沟通口径不一** — 多部门各说各话会与政策、法律冲突; 必须指定单一沟通渠道。
- **福利不透明 = 无价值** — 员工不知晓的福利不产生回报价值, 沟通是总回报落地的一环。
- **福利承诺当作短期资金池** — Studebaker 式暴雷说明: 长期给付承诺是负债, 要看资金充足率与监管。

### 方法论局限 / 适用边界

- **美国法律语境 + 阈值随时会变**: FMLA 12 周/50 人/1250 小时、COBRA 60 天窗口、WARN 60 日历日与人数门槛等数字都会随法规修订而变——本 skill 中的任何具体数字都必须"用前查证", 且各州差异极大。
- 书成稿于 COVID 之后, 育儿危机、远程工作、零工经济等结论章议题时间戳明显, 福利设计语境已被疫情塑形。
- 雇主视角: 从 HR 与经理角度写作, 员工始终是"管理的对象", 较少处理员工自身能动性与权力不对等。
- 假设组织有成型的 HR 部门、预算与信息系统 — 对最需要帮助的中小企业/初创是空中楼阁。

### 容易混淆的邻近方法论

- **总回报模型 (total rewards)**: 福利是"间接薪酬"一环; 砍任何一项福利要放回总回报系统看整体价值, 别孤立算现金。
- **FMLA key employee 与日常意义的"骨干"**: key employee 是 FMLA 精确法律概念 (75 英里内薪酬前 10% 的受薪员工, 可被豁免工作恢复义务), 不等于谁骨干谁就是 key employee。

## 快速理解: 5 个示例问题

用这 5 个最常被问到的场景快速上手本 skill, 每个问题都对应它真正触发的处理动作:

1. **员工要请 12 周'产假', 公司必须准吗? 流程怎么走?** — FMLA 门槛核对 (50人/12个月/1250小时)
2. **员工离职后, 他的医保还能续吗? 谁来交钱?** — COBRA 规则 (全额自付 + 2% / 60 天窗口)
3. **我们 120 人, 要裁 60 人, 需要提前 60 天通知吗?** — WARN 触发线核对
4. **想评估要不要砍掉健身补贴, 怎么判断对整体价值的影响?** — 放回总回报模型看整体价值
5. **员工请病假照顾生病家人, 但我们只有 30 人。** — 规模门槛判定: 不达 FMLA, 转查州法与公司政策
